## 1. 背景与目标

### 1.1 背景
目标用户是小红书上的生活记录、年度回顾人群。他们有大量照片，但缺少低成本把照片整理成“可分享成品”的方式。照片月历的价值不是替代相册，而是把已有照片快速变成一张有仪式感、可发布的月历图。

### 1.2 产品定位
**轻制作工具**：把相册里的照片整理成可分享的月历图。  
不是长期打卡记录工具，不是云相册，不是 AI 相册管理器。

### 1.3 V1 要验证的问题
1. 用户是否愿意点选照片填入月历？
2. 用户是否能顺利完成并导出？
3. 导出成品是否愿意保存、发小红书？
4. 用户对“AI 自动回填”是否有付费意愿？

### 1.4 成功指标假设
上线后 4 周观察：
- 打开 → 选图率 ≥ 30%
- 选图用户 → 导出率 ≥ 30%
- 导出用户 → 保存/点击分享 ≥ 50%
- 二次访问率有可观察数据
- 导出后 AI 付费意愿问卷中，愿意付 9.9/19.9 的比例 ≥ 10%

以上为假设指标，用于判断是否进入 V1.5，不作为上线硬门槛。

## 2. 用户与核心场景

### 2.1 目标用户
- 小红书生活记录用户
- 喜欢月度总结、年度回顾、手帐感内容
- 手机相册照片多，但不会主动整理
- 愿意为“好看、可分享”的成品投入 3–10 分钟

### 2.2 核心场景
1. 月末或年末，从相册挑照片，填入月历。
2. 调整模板和背景，导出单月图。
3. 发小红书，配一句“我的 X 月照片月历”。
4. 少数用户尝试全年总览图。

---

## 3. 产品原则

1. **本地优先**：不上传照片，不做账号，作品保存在本机浏览器。
2. **不阻塞主流程**：EXIF 不一致只提示，不强制弹窗打断。
3. **少量照片也好看**：空白格是留白，不是缺陷。
4. **免费无水印**：V1 导出全部免费、无水印。
5. **单月优先**：单月 3:4 竖版是主导出；全年图是 Beta。
6. **先看到成品感**：首屏和模板预览要让用户知道“做出来是什么样”。

- AI 自动批量选图、AI 回填（V1.5 付费增值）

- 自定义时间段合集（V2）
- 拼图、多图格子、视频导出
- 用户账号、云端存储、跨设备同步
- 社区、评论、点赞
- 强制水印
- 饱和度、透明度滑杆
- 多人协作

## 5. 用户主流程

### 5.1 首次打开
1. 打开 H5，加载当月月历，今日高亮。
2. 首屏显示轻引导：“点今天，放第一张照片”。
3. 模板预览区展示 3–5 张示例照片的成品效果。
4. 用户点击日期格子 → 唤起相册选图。

### 5.2 填图流程
1. 选图后前端压缩并读取 EXIF。
2. 拍摄日期 = 当前格子日期：直接填入，无弹窗。
3. 拍摄日期 ≠ 当前格子日期：默认填入当前格子，底部 toast 提示：
   - “这张拍摄于 6月3日，已放入 6月10日 [移到6月3日]”
4. 用户点“移到”：
   - 目标日期为空：照片移动到目标日期，当前格清空。
   - 目标日期已有照片：二次确认“替换该日期照片？”。
5. 用户不点：toast 4 秒后消失，照片保留当前格。
6. 无 EXIF：直接填入，轻提示“未读取到拍摄时间”。

### 5.3 编辑与导出
1. 点击已填格子 → 底部操作：“更换 / 删除 / 查看”。
2. 打开样式面板：切换模板、背景色、滤镜、自定义背景图。
3. 点导出 → 选择“单月图”或“全年总览 Beta”。
4. 生成后展示成功弹层：“保存图片 / 复制小红书文案”。
5. 微信内提示长按保存；Safari 走下载；失败给兜底提示。

## 6. 页面与信息架构

V1 采用单页 H5 + 底部抽屉/弹层，不做复杂路由。

### 6.1 主页面
- 顶部：产品名、当前年月、左右切换、已填 X 天
- 中部：7 列月历网格，日期格 1:1 照片区
- 底部：样式按钮、导出按钮
- 首屏空状态引导

### 6.2 样式抽屉
- 模板：极简白 / 暖纸感 / 深色胶片
- 背景：纯色 / 纸纹 / 自定义背景图
- 照片滤镜：原图 / 暖 / 黑白
- 自定义背景图自动模糊 + 暗化，保证照片可读

### 6.3 导出弹层
- 单月图（主推）
- 全年横版 Beta（4列×3行）
- 全年竖版 Beta（3列×4行）
- 生成进度、成功保存、复制文案、失败提示

## 7. 功能需求详细说明

### 7.1 月历视图

| 编号 | 需求 | 说明 |
|---|---|---|
| CAL-01 | 默认当月 | 打开显示当前年月 |
| CAL-02 | 今日高亮 | 仅视觉高亮，不特殊交互 |
| CAL-03 | 周起始周一 | V1 固定，不做设置 |
| CAL-04 | 月份切换 | 左右按钮或滑动，支持跨年 |
| CAL-05 | 一格一张 | 无照片显示空白日期 |
| CAL-06 | 点击空格子 | 唤起单张选图 |
| CAL-07 | 点击已填格子 | 底部操作：更换/删除/查看 |
| CAL-08 | 照片裁切 | 网格内统一 1:1 cover |
| CAL-09 | 已填进度 | 显示“已填 X 天”，不做打卡压力 |
| CAL-10 | 少量照片可导出 | 填 3–5 张即可导出 |

**验收标准**
- 打开默认当月，今日高亮正确。
- 切换月份后日期与星期对应正确，跨年正确。
- 空格子可选图，已填格子可替换、删除、查看。
- 删除后格子恢复空白，本地草稿同步更新。

### 7.2 选图与 EXIF

| 编号 | 需求 | 说明 |
|---|---|---|
| EXIF-01 | 本地解析 | 前端读取，不上传 |
| EXIF-02 | 时间字段优先级 | DateTimeOriginal → DateTimeDigitized → CreateDate |
| EXIF-03 | 一致直接填入 | 不弹窗 |
| EXIF-04 | 不一致非阻塞 | 默认填入当前格，toast 提供“移到对应日期” |
| EXIF-05 | 无 EXIF | 直接填入，轻提示 |
| EXIF-06 | 移动冲突 | 目标日期已有照片时确认替换 |
| EXIF-07 | 选图压缩 | 长边压缩至 1600–2000，JPEG 0.85，统一转 JPEG |
| EXIF-08 | HEIC/方向 | 尝试浏览器解码；失败提示换图或系统转换；统一处理方向 |

**验收标准**
- 拍摄日期与格子一致时无弹窗。
- 不一致时照片仍填入当前格，toast 出现且可点“移到”。
- 点“移到”后当前格清空，目标格填入；冲突时出现确认。
- 无 EXIF 不阻断填图。
- 大图选入后不导致页面明显卡死。

### 7.3 本地草稿

| 编号 | 需求 | 说明 |
|---|---|---|
| STO-01 | IndexedDB 保存 | 保存压缩后的照片 Blob、日期映射、样式、模板、背景 |
| STO-02 | 自动保存 | 填图、删除、换图、样式变更后 300ms 防抖保存 |
| STO-03 | 恢复 | 重开恢复上次编辑年月与内容 |
| STO-04 | 不存原图 | 只存压缩图，降低配额压力 |
| STO-05 | 配额异常 | QuotaExceededError 时提示“存储空间不足，请导出后清理” |
| STO-06 | 隐私说明 | 页面说明“作品仅保存在本机浏览器，清除浏览器数据会丢失” |

**验收标准**
- 填 5 张图后刷新页面，照片与样式恢复。
- 删除照片后刷新，删除状态保持。
- 存储失败有明确提示，不静默丢失。

### 7.4 样式系统

| 编号     | 需求              | 说明                |
| ------ | --------------- | ----------------- |
| STY-01 | 3 套模板           | 极简白、暖纸感、深色胶片      |
| STY-02 | 模板预览            | 用示例照片展示成品感        |
| STY-03 | 背景纯色            | 每套模板有默认色，可切换      |
| STY-04 | 照片滤镜（更新：去掉这个功能） | 原图 / 暖 / 黑白       |
| STY-05 | 自定义背景图          | 上传后自动模糊 + 暗化，保证可读 |
| STY-06 | 不做滑杆            | V1 不做饱和度、透明度滑杆    |

**验收标准**
- 切换模板后月历视觉即时变化。
- 自定义背景图不导致日期和照片不可读。
- 样式变更自动保存并恢复。

### 7.5 导出

| 编号 | 需求 | 说明 |
|---|---|---|
| EXP-01 | 单月 3:4 竖版 | 主推，逻辑 1080×1440，2x 导出 |
| EXP-02 | 全年横版 Beta | 4列×3行，原“3行×4列” |
| EXP-03 | 全年竖版 Beta | 3列×4行，适合手机 |
| EXP-04 | 空白格淡化 | 全年图空白格浅色显示，不突兀 |
| EXP-05 | Canvas 自绘 | 控制清晰度、字体、裁切 |
| EXP-06 | 无水印免费 | V1 全部免费无水印 |
| EXP-07 | 保存引导 | 微信长按保存；Safari 下载；失败兜底 |
| EXP-08 | 导出后操作 | “保存图片 / 复制小红书文案” |
| EXP-09 | 导出提示 | 全年图提示“空白格会保留，填更多月份效果更好” |

**验收标准**
- 单月图导出清晰，照片不拉伸，日期正确。
- 全年横版/竖版月份顺序正确。
- 微信内保存路径有提示，失败不白屏。
- 导出不加水印，不需要登录。

### 7.6 分享辅助
- 复制文案示例：“我的 X 月照片月历｜把相册里的日子拼回来了 #照片月历”
- 不强制发布，不校验是否发布。

### 7.7 埋点与意愿收集

匿名埋点，不上传照片、不收集通讯录。事件表：

| 事件 | 触发 |
|---|---|
| app_open | 打开 H5 |
| month_switch | 切换月份 |
| photo_select | 选图成功 |
| exif_mismatch_shown | 出现 EXIF 不一致提示 |
| exif_move_click | 点击“移到对应日期” |
| photo_delete | 删除照片 |
| photo_replace | 替换照片 |
| template_switch | 切换模板 |
| export_single | 导出单月 |
| export_year_h | 导出全年横版 |
| export_year_v | 导出全年竖版 |
| export_success | 导出成功 |
| save_click | 点击保存 |
| caption_copy | 复制文案 |
| ai_willingness | 提交 AI 付费意愿 |
| revisit | 二次访问 |

AI 意愿问卷：导出成功后低频出现，每浏览器 7 天最多一次。选项：不愿 / 9.9 / 19.9 / 其他。不得阻塞保存。

## 8. 非功能需求

| 类别 | 要求 |
|---|---|
| 技术栈 | Vue3 + Vite，移动端 H5，HTTPS |
| 兼容 | iOS Safari、微信内置浏览器、Android Chrome/微信 |

| 部署 | 国内可访问；准备“复制链接到浏览器打开”兜底 |
| 数据 | 不存账号，不做云端；IndexedDB 版本化 |

## 9. 数据模型（简版）

```js
Project {
  id: "default",
  version: 1,
  year: 2026,
  month: 11,
  entries: {
    "2026-11-24": { blob: Blob, width: 1600, height: 1200, createdAt: 0 }
  },
  style: {
    templateId: "minimal-white",
    backgroundColor: "#ffffff",
    filter: "original",
    backgroundImageBlob: null
  },
  lastEditedAt: 0
}
```

存储原则：只存压缩图 Blob；背景图也压缩；保存防抖 300ms；读取失败降级为空月历并提示。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 用户照片无 EXIF | 不阻断，直接填入 |
| HEIC/方向异常 | 统一转 JPEG，失败提示 |
| 微信保存图片困难 | 长按保存引导 + 新窗口兜底 |
| IndexedDB 配额不足 | 压缩入库，异常提示导出清理 |
| 全年图空白多不好看 | 空白淡化，标 Beta，主推单月 |
| 小红书外链限制 | HTTPS、国内可访问、复制链接兜底 |
| 埋点引发隐私顾虑 | 匿名、不上传照片、页面说明 |
| 样式参数过多 | V1 砍滑杆，只留模板/背景/滤镜 |
