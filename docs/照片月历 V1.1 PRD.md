# 照片月历 V1.1 产品需求文档（PRD）

- 文档版本：V1.1
- 创建日期：2026-11-26
- 最近更新：2026-11-27
- 状态：需求已明确，功能开发与验收进行中
- 基线版本：V1.0
- 产品定位：默认快速生成，同时保留足够的个性化调整能力

---

## 1. 版本说明

V1.1 是在 V1.0 基础上的体验与可靠性优化版本，重点解决首次使用理解门槛、多照片导入效率、日期安排灵活性，以及已发现的视觉、导出和保存问题。

V1.0 原始 PRD 是历史基线，不得直接覆盖或修改。新增和调整的需求统一记录在 V1.1 PRD 和决策记录中。

## 2. 产品原则

- 本地优先：照片不上传，作品保存在用户本地。
- 默认快速生成：尽量减少用户操作步骤。
- 保留个性化调整：允许用户调整照片、日期和月历样式。
- 少量照片也能生成好看的作品。
- 不增加不必要的账号、云端存储和复杂操作。
- 免费无水印的产品原则保持不变。

## 3. V1.1 功能范围

### 3.1 首次使用引导

需求编号：IMP-GUIDE-001；优先级：P1。

目标：帮助第一次使用的用户快速理解产品并开始制作。

需求：
1. 首次打开且没有照片时，展示简短的使用引导。
2. 引导视觉必须沿用照片月历现有的设计语言、模板色彩、字体与控件风格，不得像外部嵌入的独立产品。
3. 手机端采用底部面板形式，桌面端采用适当居中的面板；不遮挡主要操作。
4. 明确说明添加照片、安排日期、调整样式和导出的基本流程。
5. 用户开始制作或已有照片后自动收起。
6. 提供可再次查看的帮助入口。
7. 示例内容如有展示，仅用于说明，不得混入用户实际作品。

验收标准：
- 手机和电脑布局正常。
- 极简白、暖纸感、深色胶片及自定义背景下均与产品视觉协调。
- 老用户再次访问时不重复展示首次引导。
- 帮助入口可以再次打开。

### 3.2 多照片批量导入

需求编号：IMP-BATCH-001；优先级：P0。

目标：允许用户一次选择多张照片，减少逐张添加的操作成本。

需求：
1. 支持一次选择多张照片。
2. 自动尝试读取照片拍摄时间，但不强制使用 EXIF 日期。
3. 导入前展示照片缩略图和目标日期；不展示冗长文件名，来源日期仅在普通批量导入中作为辅助信息。
4. 用户可以在确认前修改日期、调整顺序、从本次待导入列表移除单张照片。
5. 不支持或无法解码的文件必须明确标记原因；该条目不可修改日期、不可排序、不可导入，但可以从列表移除。
6. 单张文件不支持或处理失败，不得阻断其他有效照片。
7. 用户确认后统一写入月历；取消预览不得产生任何照片写入。
8. 已有照片的日期不得被静默覆盖；但用户从某个日期格（包括已有照片日期的“更换”操作）发起多选时，第一张有效照片默认锚定该日期，并在预览中明确提示替换。
9. 成功导入后，用户仍可通过月历原有的照片操作入口查看、更换和删除照片。

### 3.3 批量导入日期安排

需求编号：IMP-BATCH-002；优先级：P0。

**普通“添加照片”入口**
1. 有可读取拍摄日期的照片，优先使用对应日期。
2. 无拍摄日期的照片按原始选择顺序，从用户指定的起始日期开始填入空日期。
3. EXIF 读取异步完成也不得打乱文件选择顺序。
4. 用户可在确认前修改日期、拖动调整顺序；移除条目后重新计算自动分配日期。
5. 不提供“按拍摄日期 / 按选择顺序”的模式切换。

**从指定日期格发起多张照片导入**
1. 以用户点击的日期为起点，按照片选择顺序连续安排。
2. 默认选择“替换已有照片”。例如从 18 日导入两张，分别安排到 18、19 日；若两天已有照片，确认后分别替换。
3. 用户可以切换为“只放入空格”，保留原照片并跳过已有照片日期，继续向后安排。
4. 此入口以用户指定的日期和选择顺序为准，不使用 EXIF 日期改变顺序。
5. 用户可以在确认前拖动排序、修改目标日期或移除单张照片。

**冲突与确认**
- 普通批量导入遇到已有照片日期时，必须提示并阻止覆盖。
- 指定日期格入口的替换行为必须明确显示“替换已有照片 / 只放入空格”选项，默认替换。
- 导入列表内部重复日期必须阻止确认。
- 日期分配与排序只作用于待导入列表，确认前不得写入作品。
- 鼠标和触屏均支持整行拖动调整；交互不得妨碍日期输入和移除按钮。


### 3.4 已确认的其他修复项

1. 自定义背景图片下，当天日期格样式必须正常显示。
2. 背景遮罩透明度为 0 时，导出结果必须保持完全透明遮罩，不得回退到默认值。
3. 单月与全年导出的分享文案应正确显示对应年月或年份。
4. 草稿保存失败时，提示用户及时导出备份；存储空间不足时提供明确提示。
5. 背景图上传、移除及照片修改后的草稿保存必须保持最新状态；异步写入不得让旧数据覆盖新数据，页面隐藏或离开时应主动刷新待保存内容。
6. 隐私说明面向普通用户表达，不展示 IndexedDB 等内部技术术语。
6. AI 付费意愿问卷已取消，不属于 V1.1 范围。
