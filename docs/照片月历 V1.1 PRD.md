## 1. 版本说明

V1.1 是在 V1.0 基础上的体验与可靠性优化版本。

本版本不改变产品的核心定位和基本原则，重点解决：

1. 首次使用时的理解和操作门槛。
2. 多照片导入效率，尤其是照片缺失 EXIF 日期的情况。
3. 已发现的视觉、导出和保存问题。
4. 用户隐私说明和访问安全问题。

V1.0 原始 PRD 是产品历史基线，不得直接覆盖或修改。新增和调整的需求统一记录在 V1.1 PRD 和变更记录中。

## 2. 产品原则

V1.1 继续遵循 V1.0 的产品原则：

- 本地优先：照片不上传，作品保存在用户本地。
- 默认快速生成：尽量减少用户操作步骤。
- 保留个性化调整：允许用户调整照片和月历样式。
- 少量照片也能生成好看的作品。
- 不增加不必要的账号、云端存储和复杂操作。
- 免费无水印的产品原则保持不变。

## 3. V1.1 功能范围

### 3.1 首次使用引导

需求编号：IMP-GUIDE-001

优先级：P1

目标：帮助第一次使用的用户快速理解产品，并开始制作月历。

需求：

1. 首次打开且没有照片时，展示简短的使用引导。
2. 展示月历成品示例，让用户理解最终效果。
3. 明确提示用户如何添加照片。
4. 手机和电脑采用适配布局。
5. 用户开始制作后，引导自动收起，避免反复打扰。
6. 提供可再次查看的帮助入口。
7. 示例照片仅用于展示，不得混入用户实际作品。

验收标准：

- 手机和电脑均能正常展示。
- 不遮挡主要操作。
- 用户可以顺利完成第一次照片添加和月历制作。
- 老用户再次访问时，不重复展示完整的新手引导。

### 3.2 多照片批量导入

需求编号：IMP-BATCH-001

优先级：P0

目标：允许用户一次选择多张照片，减少逐张添加照片的操作成本。

需求：

1. 支持一次选择多张照片。
2. 自动尝试读取照片拍摄时间。
3. 能读取 EXIF 日期的照片，优先使用拍摄日期。
4. 无法读取 EXIF 日期的照片，不得阻断整个导入流程。
5. 导入前展示照片与目标日期的对应关系。
6. 用户确认后统一写入月历。
7. 已有照片的日期不得被静默覆盖。
8. 单张照片处理失败时，不应导致其他照片全部导入失败。
